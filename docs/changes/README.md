# Change records

One record per change, named `NNNN-<slug>.md`, from `templates/change-record.md`. A record carries the evidence git cannot: `## Verification` is required, `## Context` is optional, and an optional `Decision: <path>` line must resolve to a record under `docs/decisions/`. What was decided lives there; what changed lives in git. This index is exempt from the section check.
